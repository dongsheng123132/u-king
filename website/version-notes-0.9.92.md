本版继续修 Hermes 和终端这两条线，另有一批让界面更好懂的小改动：

① Hermes 又修了一处 404 🔌——上一版把「配置写到哪」修对了，这一版把「写进文件里的内容」也修对了：有客户机的配置被系统自带 PowerShell 写出一个看不见的隐藏字符（BOM 头），导致配置被重复写入、端点读错，Hermes 请求打到不存在的地方 → 404。现在写入前会自动清掉这个隐藏字符。另一个真凶是「API 模式」不匹配：Hermes 按 Anthropic 格式发请求、你的供应商却只认 OpenAI 格式（或反过来），照样 404。现在会看当前模式自动选对端点。下次重新配置时，坏掉的配置会被自动纠正。

② 「用量曲线画出一条假扣费」修好了 📊——有台机器上「使用数据」的曲线看着像在持续扣费，其实是我们自己的 bug：调系统时间的那条命令在某些电脑上把命令文本（Get-Date）当成了日期写进记录，堆了一千多条假数据。现在记录前会先校验是不是真日期，假数据直接过滤掉，不展示、也不算趋势。

③ 终端不再是一片死黑 🎨——老主题只有 6 个颜色，ls / git 的彩色输出全变成灰白，小白看着就是一团乱码。现在补全了 16 色，「绿色=成功 / 红色=报错」一眼可辨；还加了**三套配色**（暗黑默认 / 浅色护眼 / 复古绿），终端标签栏点调色板图标随时切，工作台、独立页、TUI 应用所有终端一起换肤。

④ 终端新手引导卡 💡——第一次开终端的客户，顶部会有一张「新手看这里」卡片：点一下「跟 Claude 聊天」就进对话，不用记命令；还有写周报 / 总结会议 / 做表格 / 写代码 / 找 Bug / 翻译文档六个快捷词，点一下直接跑。不想要点 × 永久关掉，以后点标签栏的小灯泡还能重新打开。

⑤ 报错不再误导你去换 Key 🗝️——如果账户额度用完了或已被冻结（Key 本身是好的），以前提示会往「Key 无效」上引，让客户白折腾换 Key。现在分开了：额度问题会直接说「去充值」。

⑥ 回访直接进终端 🚀——装过工具的电脑，重新打开 U-King 直接落在终端页（干活的地方），不再先进管家页。没装过工具的照旧先进装机向导。

本版无新功能，全部是修复和体验加固，升级无感。
