本版是一次「清库存」稳定性发版，主要修了这些：

① 双击开重了终于只会开一个 🪟——以前关窗口只是缩到托盘，你以为关了、再双击又起一个，一台电脑上能攒出 3 个 U-King（还混着旧版本）。现在做了单实例保护，怎么点都只有一份，不浪费资源也不扣冤枉钱。

② Hermes 的模型配置修好了 🔌——有个客户机一直报 404，查下来是我们把配置写进了 Hermes 根本不读的目录：界面一路显示「配置成功」，实际打的是另一个地址。现在家目录改成直接问 Hermes 自己要，写哪读哪一致；还加了一条诊断命令，以后报错第一句话就能定位。

③ 低分辨率屏幕不再挤成一团 📐——1366×768 这种小屏上，以前界面左边挤得截断、右边大片空白（从来没做过窄屏适配）。这次做了响应式，窄屏也能正常看。

④ Mac 上「爱马仕和 codex」装不上了，修好 🍎——Mac 和 Windows 读同一份安装清单，PowerShell 步骤在 Mac 上被当成 sh 执行，必失败。现在按平台分流。

⑤ ClawX 放回首页 🦞——之前一刀切把它收进「进阶 / App 版」，结果「不主推」变成了「找不到」。有些客户就是冲这个图形界面来的，现在首页又能看到它了（仍不默认安装）。

⑥ 装机更稳了 🛠️——便携 Python 解压时跳过调试符号文件（.pdb），这类文件正是杀软最爱盯着卡住的那批；装完的验证也更严格。

⑦ 技能包补全 📦——技能同步补上了 Codex 的落点，Hermes 从「实验性」转正，实测 13 个包全部被各家 AI 工具正常识别。

另外：终端测试的稳定性检查也加固了（冷启动机器上不再误判）。本版无新功能，全部是修复和加固，升级无感。
