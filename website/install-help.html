装不上怎么办

90% 的安装失败都是下面这 4 个原因之一 —— 对症补一下就好

U-King 的命令行工具（Claude Code / Codex CLI / OpenClaw / Hermes）都是用 npm / pip 自动装的。装不上时别急着重装，先看是不是中了下面的常见坑。每条都附了可一键复制的命令。

1客户机有代理（clash / v2ray）→ npm 被拦死

这是最常见的原因。代理会把 npm 的下载请求劫持，表现为：装到一半卡住不动、报 ETIMEDOUT / ECONNRESET / lookup ""。

在终端里逐条执行，清掉写死在全局配置里的代理：

npm config delete proxy --location=global
npm config delete https-proxy --location=global
npm config delete proxy
npm config delete https-proxy
npm cache clean --force

清完再回 U-King 点「重试」即可。临时关掉代理软件再装也行。

2没装 Node.js → 敲 npm 提示「不是内部或外部命令」

Claude Code / Codex CLI / OpenClaw 都依赖 Node.js。U-King 一般会自动装便携版；若没成，自己装一下：

Node.js 官网 国内镜像直链（v22 Win x64）

下 LTS 版（Windows 选 .msi），一路下一步装完，关掉所有命令行窗口重开，再回 U-King 重试。

3PowerShell 禁脚本 → 报「无法加载 xxx.ps1」

装完工具一运行就报「因为在此系统上禁止运行脚本」。免管理员放开一次即可（只影响当前用户）：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

提示确认时输入 Y 回车。或者改用 CMD（命令提示符）敲命令，CMD 不受这个限制。

4国内镜像同步滞后 / 缺包 → 换源或走官方

个别新版本国内镜像还没同步，会报缺包。可临时改用官方源（必要时挂代理）装：

# 用官方 npm 源装（示例：Claude Code，其它工具换包名即可）
npm install -g @anthropic-ai/claude-code

# 或显式指定国内镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

❓ 还是不行？

装上了，U-King 还是说没装？
在命令行里敲 工具名 --version（如 claude --version）能打印版本号才算真装好。确认后回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 再重新打开（右下角托盘图标 → 退出，再双击 U-King.exe）。
磁盘满了？
这些工具加运行时要几百 MB。C 盘空间不足时 npm 会报莫名其妙的错。清一下垃圾或换个盘再装。
实在装不上，能找人帮忙吗？
可以。U-King 里点「报告问题」会把日志自动发给我们，或到官网 u-king.org 联系。我们也支持远程协助装机。
