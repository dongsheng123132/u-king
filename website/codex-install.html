Codex 桌面版 · 手动安装

自动安装没成功时，照这个页面点几下就能装好

为什么要手动装？ Codex 桌面版是 OpenAI 官方图形应用。Windows 自动安装依赖微软商店 / winget，可能被公司安全策略或杀毒软件挡住；Mac 则需要下载 DMG 后拖到 Applications。按你的系统任选一种方式，成功一个就行。

正常主流程：在 U-King 的「Codex 专区」点一键安装后，U-King 会先试微软商店；商店不可用时自动下载 MSIX 镜像兜底；安装成功后会自动写好虾盘云配置。余额够就能直接用，余额不够会红色提示去充值。

这个页面只在自动安装被系统策略、杀毒、商店异常拦住时使用。你手动把 Codex 装好后，回到 U-King 点「刷新」，再点「一键接虾盘云」即可恢复同一个闭环。

1方式一（最推荐）：微软商店一键装

点下面的按钮，会自动打开 微软商店 并跳到 Codex 页面：

打开微软商店（应用内） 商店网页版（用浏览器）

  1. 在打开的 Codex 页面，点蓝色的 获取 / 安装 按钮。
  2. 如果提示登录微软账号，登录一下即可（免费账号就行）。
  3. 之后会在后台自动下载安装，进度条跑完就算装好了（包较大，慢网耐心等几分钟）。
💡 商店 App 打不开？就点上面第二个「商店网页版」，用浏览器打开同一个官方页面，点【获取】会唤起商店继续装。

2Windows 方式二：直接下载安装包

商店两种都不行，就直接下安装包（约 664MB）：

官方下载（Windows） 国内镜像（.msix）

  1. 点上面按钮，浏览器开始下载（慢网请耐心等待，别关页面）。
  2. 下完后，在浏览器右上角「下载」里找到这个文件，双击它。
  3. 弹出安装窗口后点 安装，等进度走完。

3macOS：下载官方 DMG

Mac 不走静默安装。点对应芯片的官方包，下完后打开 DMG，把 Codex.app 拖到 Applications / 应用程序：

Mac Apple Silicon（M 系列） Mac Intel OpenAI 官方页面

  1. 不知道芯片？点屏幕左上角苹果图标 →「关于本机」。显示 M1/M2/M3/M4 就选 Apple Silicon；显示 Intel 就选 Intel。
  2. 如果提示来自互联网，点「打开」。若被隔离拦住，可在系统设置 → 隐私与安全性里允许打开。
  3. 装完回 U-King 点「刷新 / 重新检测」。还没识别就彻底退出 U-King 再打开。

4装好后：重启 U-King 才能识别 ⚠️

重要：微软商店是「后台慢慢装」的；Mac 拖入 Applications 后也可能需要重新检测。刚装完 U-King 可能暂时还检测不到（显示「未安装」是正常的，别慌）。

请这样做：

  1. 等商店里的 Codex 进度条 100% 装完（商店里会变成「打开」按钮）。
  2. 回到 U-King，点界面里的「重新检测」。
  3. 要是还没识别，把 U-King 整个关掉再重新打开（彻底退出，不是缩到托盘）——重开后基本就能认出 Codex 了。
💡 想彻底退出 U-King：右键屏幕右下角托盘里的 U-King 图标 → 退出；或先点「缩到托盘」再从托盘退出，然后双击桌面 / U 盘里的 U-King.exe 重新打开。

5能打开 Codex 但提示余额不足？

这不是安装失败，也不是 Key 失效。Codex 使用的是 GPT 系编程模型，单次请求会预扣一小笔余额；如果当前余额不够这次请求，U-King 会红色提示充值。

  1. 回 U-King 点「虾盘云余额 / 充值」。
  2. 充值到账后重新打开 Codex 或重新发一次任务。
  3. 仍然失败时，在 U-King「Codex 专区」点「一键接虾盘云」重新写配置。

❓ 常见问题

点「获取」后没反应 / 一直转圈？
微软商店偶尔抽风。在商店里点左上角刷新、或关掉商店重开，再点一次【获取】。还不行就改用「方式二」直接下安装包双击装。
提示「需要登录」？
用任意微软账号登录即可（注册免费）。Codex 应用本身免费下载，用 AI 的额度由 U-King 的虾盘云驱动提供，跟微软账号无关。
双击安装包提示「无法安装」？
多半是系统关了「旁加载应用」。打开 Windows 设置 → 隐私和安全性 → 开发者选项，把「旁加载应用」或「开发人员模式」打开，再双击一次安装包。或者直接走「方式一」从商店装。
装好了，U-King 还是说没装？
先确认商店里 Codex 已经是「打开」状态（=装完了）。然后彻底关闭 U-King 再重新打开——商店应用刚装完，需要重启程序才能被识别。重开后进「AI 设置 → Codex 体检」点「重新体检」即可。
