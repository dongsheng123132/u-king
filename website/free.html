Free Router（本地免费路由网关）· 手动安装指南

U-King 界面里的一键安装如果失效（上游仓库变动、下载被拦等），用下面的手动步骤，效果完全一样：

  1. 装 Node.js 20 或更高版本（官网下载，一路下一步）
  2. 领取 OpenRouter Key：openrouter.ai/keys（注册即送免费档）
  3. 下载项目：git clone https://github.com/www222fff/free-router.git（或到仓库页面点 Code → Download ZIP 解压）
  4. 进目录，复制 .env.example 为 .env，把 OPENROUTER_API_KEY= 后面填上你的 Key
  5. 启动：node server.mjs（保持窗口开着；关掉窗口网关就停了）
  6. 在 U-King「供应商库」添加自定义供应商：地址 http://127.0.0.1:8787/v1，模型名 free-best，Key 随便填 local

第三方开源项目，U-King 未做安全审计；免费模型多数需要代理环境。本指南更新日期见上方「人工核验」。
