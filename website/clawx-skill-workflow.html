用 ClawX 做事，就三件事

找一个「技能」 → 配一个「大模型 Key」 → 说一句话让它干活
先理解俩词，后面就不绕了：
· 技能 = 一份「教 AI 怎么做某件事」的说明书（比如怎么做视频、怎么画漫画）。从 skillhub.cn 复制，粘进 ClawX。
· 大模型 Key = AI 的「大脑」和「油费」。去模型公司申请一串 sk-，粘进 ClawX，它就有脑子、能扣费干活了。
技能负责「会做」，Key 负责「有脑子做」，两个都要有。
1

去技能市场找一个技能

打开腾讯技能市场 skillhub.cn，注册（手机号即可）后搜你想做的事的关键词，挑一个现成技能：

🎬 视频🖼️ 作图📖 小说 🎨 漫画 / 分镜💻 编程✍️ 写作排版

进到技能详情页，把里面的技能内容（提示词 / 配置）复制下来。

打开技能市场 skillhub.cn 举例：做视频用 openclaw-v3

2

把技能粘进 ClawX

回到 ClawX，新建一个对话 / 智能体，把刚复制的技能内容粘进去，让它「记住要按这个来做」。

不同技能放的位置略有差别，照技能页的说明放即可 —— 多数就是直接发给 ClawX、或贴进它的「系统提示 / 技能」栏。

3

申请一个大模型 Key（关键一步）

光有技能还不够，得给 ClawX 一个「大脑」。去任意一家模型公司申请 Key：

  • 火山引擎（豆包 · 即梦） —— 作图、视频最值得用这家。
  • DeepSeek —— 最便宜，写作 / 编程 / 日常对话够用。
  • 智谱 GLM / Kimi —— 各有免费额度 / 超长文本。
  • 虾盘云（U-King 内置） —— 嫌麻烦?这个免注册免实名、开箱即用，充值即用。

划重点：国内平台基本都要先「实名认证」才发 Key（身份证 / 刷脸）。没实名就拿不到 Key，这步绕不过去，先做完。详细注册 + 实名 + 申请步骤看下面这篇 ↓

各家 Key 申请教程（含实名认证）

4

把 Key 粘进 ClawX，让它记住

回到 ClawX，进「模型设置 / 设置」，选你申请的那家服务商，把 sk- 那串 Key 粘进去保存。

保存后 ClawX 就记住了，下次不用再填。以后你说「用刚才那个技能帮我做个视频」，它就自动用这个技能 + 这个 Key 去干活。

想换一家模型?重复第 3、4 步换个 Key 即可，技能不用动。

5

开干 —— 说一句话就行

都配好后，像聊天一样跟 ClawX 说你要做什么：

  • 「用 openclaw-v3 技能，帮我做一条介绍我家猫的短视频」
  • 「按漫画技能，把这段故事画成 4 格漫画」
  • 「用写作技能，帮我写一篇公众号推文」

它会照着技能、用你配的模型一步步做出来。第一次配置花几分钟，以后都是一句话的事。
