2026-10-21 新版本

U-King 1.4.9 发布：AI 只读 3 份技能说明，其余改软件内部调用

这版继续省钱：AI 工具里默认只留 3 份技能说明（作图视频 / 读文档 / 搭工作台），其余技能收进软件自己用，不再占每一轮对话的上下文。

出 PPT、出 Word、出 Excel、出 CAD 图纸这些能力都还在，只是改成软件内部直接调用，不经过 AI 上下文、也不花 token；相比最初，AI 每轮要读的技能说明少了约六成。

你自己手动装过的技能包不会被清理（升级时点名跳过）；看图默认走 DeepSeek 原生，不再依赖单独的识图技能包。

源码开源：github.com/dongsheng123132/u-king（Apache-2.0）

2026-10-21 版本回顾

U-King 1.4.7 / 1.4.8 回顾：工作台回原样，工具目录收敛到 11 个

工作台改回大家熟悉的样子：对话（Claude Code 底座）+ 终端 + 左侧项目/会话，切页不丢终端和对话；维护助手只负责装机/故障兜底，每次进去都是全新对话，左边保留历史记录。

「我的 AI」精简到 11 个工具（Claude Code、Codex、Codex 桌面版、ClawX、Hermes、DSH、pi、OpenCode、UU 远程、WorkBuddy、magpie），图形工具点开直接开窗；文件树、预览面板、任务护照、git 工作树等不常用入口撤掉。

装机/升级搞不定时可以交给 AI：向导里勾「让 AI 来安装」，或工具卡点「升级失败？让 AI 修」，会自动新开一条维护对话并把脱敏后的任务填好。

模型列表默认只留 3 个国产（DeepSeek V4 Flash / V4 Pro / Kimi K3）；1.4.8 把技能包从 14 个精简到 8 个、每条对话发送的历史收窄到 1/3，长聊更省钱，官网页脚也从这一版起加上 GitHub 开源入口。
