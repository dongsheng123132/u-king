Download blocked, or double-clicking does nothing?

Warnings about unsigned software are normal — two steps fix it: ① When Edge says "This file isn't commonly downloaded", click Keep; ② if double-clicking does nothing, right-click the file → Properties → check Unblock → OK, then double-click again; in the blue SmartScreen window, click More info → Run anyway.

If the download button keeps failing, open PowerShell, paste the command below, and press Enter — it will automatically try multiple mirrors and open the installer:

irm https://u-claw.org.cn/uking/dl.ps1 | iex
Seeing "The procedure entry point ProcessPrng could not be located"?

This means your system version is too old — the file isn't corrupted and there's no virus. The full error is "The procedure entry point ProcessPrng could not be located in the dynamic link library bcryptprimitives.dll". This system API only exists on Windows 10 and above — it's missing on Windows 7 / 8 / 8.1, so the program is blocked by the OS before it can even start.

How to check your system version: Press Win + R, type winver, and press Enter — the first line of the popup will say either "Windows 7" or "Windows 10 / 11".

⚠️ When you hit this error, re-downloading, switching mirrors, disabling antivirus, and right-click "Unblock" all do nothing — the error will be identical every time. Please don't keep troubleshooting along these lines.

The only fix is upgrading to Windows 10 or 11. Also note: the installer U-King-Setup.exe will install successfully on older systems, but launching it from the desktop icon afterward still shows this same error — "it installed but won't open" is the same root cause.

Antivirus flags a "virus" and auto-deletes the file?

This is a false positive, not an actual infection. The names reported (Trojan:Win32/Cloxer, Wacatac.B!ml, and other names with !ml / Heur) are Defender's "heuristic generic names" — meaning "behaves similarly", not "matched a known virus". U-King downloads Node and installs AI tools like Claude / Codex, and this "download then run" behavior gets flagged by detection engines; the program itself isn't packed and contains no secrets. We've submitted a false-positive report to Microsoft.

Three-step recovery (Windows Security): ① Search the Start menu for Windows Security → Virus & threat protection → Protection history; ② find the U-King entry, expand "Actions", and choose Allow on device (not block/quarantine/delete); ③ download and run again.

⚠️ If you instead see something like PUAAdvertising:Win32/FlashHelper with PUA in the name, that's an ad-injecting helper unrelated to U-King — go ahead and choose "Remove".

If antivirus flags interrupt installation, you can also whitelist the install folder up front: Windows Security → Virus & threat protection → Manage settings under "Virus & threat protection settings" → scroll down to Add or remove exclusions → add the folder %USERPROFILE%\.uking.

macOS

One command installs it on Mac.

Double-clicking an unsigned dmg is easily blocked by the system. The command-line installer downloads it, moves it into Applications, and opens it automatically.

One-command install in Terminal

Press Command + Space, search for "Terminal" and open it, paste the command on the right, and press Enter.

curl -fsSL https://u-claw.org.cn/uking/install-mac.sh | sh
Fix for when you'd rather drag-install the dmg
  1. Download U-King-Mac.dmg and drag it into "Applications".
  2. Open Terminal and run:
    xattr -rd com.apple.quarantine /Applications/U-King.app

A "damaged" warning doesn't mean the file is actually corrupted — this is macOS's blanket block on unsigned apps.

If the download stalls or the connection resets, the command automatically switches mirrors; if all three fail, your network may not be able to reach these domains. Retry later, or download the dmg manually.

Can I carry it on a USB drive?
Yes. The Windows portable version is a single file, ideal for a USB drive; it can also be one-click copied to a local folder.
What if the download says the connection was reset?
The download button automatically picks a mirror. On Windows you can run irm https://u-claw.org.cn/uking/dl.ps1 | iex in PowerShell; on Mac run curl -fsSL https://u-claw.org.cn/uking/install-mac.sh | sh in Terminal. Both scripts try backup mirrors, and prompt for a manual download if all of them fail.
What if I get a blank white screen after opening it?
This is usually a missing Microsoft Edge WebView2 runtime. The installer fills it in automatically; for the portable version, install the official Microsoft WebView2 runtime and try again.
Does it work on Windows 7 / 8? What about "The procedure entry point ProcessPrng could not be located"?
No, Windows 10 or 11 is required. The installer will complete on older systems, but launching it from the icon afterward shows the same error. Press Win + R and type winver to check your system version; it will work normally after upgrading to Win10 / 11.
