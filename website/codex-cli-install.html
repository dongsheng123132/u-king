Codex CLI · 手动安装

自动装不上时，照这个页面在命令行里敲几条命令就能装好

Codex CLI 是什么？ 它是 OpenAI 官方的命令行 AI 编程工具，通过 npm（Node.js 的包管理器）安装。U-King 已经帮你接好了国内可用的虾盘云驱动，装好 CLI 就能直接用，不用再登录 OpenAI。

⚠️ 现在不要再单独安装 @openai/codex-win32-x64：新版 @openai/codex 已经把平台二进制打进主包，旧的单独平台包可能 404。下面命令只装主包，并用 --include=optional 保证可选二进制不被跳过。

🚀 嫌麻烦 / 命令老是装不上？ 直接跳到下面 【方式四 · 手动下载，点链接就行】 —— 像下普通软件一样，下载、解压、放好就完事，不用敲任何命令。

1方式一（最推荐）：U-King 内置终端里装

在 U-King 里打开终端（左侧栏「终端」），逐条复制粘贴回车。U-King 的终端已经帮你配好了便携 Node + 国内镜像，最省事：

# 1) 清掉可能写死的代理（客户机的 clash/v2ray 常把 npm 拦死）
npm config delete proxy --location=global
npm config delete https-proxy --location=global

# 2) 装 Codex CLI 主包（用国内镜像，--include=optional 强制拉平台二进制）
npm install -g @openai/codex --registry=https://registry.npmmirror.com --include=optional

# 3) 验证：能打印版本号就成功了
codex --version

最后一条能打印出版本号（类似 codex-cli 0.1xx.x），就说明装好了 ✅。回到 U-King 点「重新检测」即可。

💡 没有 U-King 内置终端、想用系统的 PowerShell / CMD 也行，命令完全一样。前提是电脑装了 Node.js（见下方方式二）。

2方式二：先装 Node.js，再用普通命令行装

如果敲 npm 提示「不是内部或外部命令」，说明缺 Node.js。先装它：

Node.js 官网下载 国内镜像直链（v22 · Windows x64）

  1. 下载 LTS 长期支持版（Windows 选 .msi），双击一路「下一步」装完。
  2. 关掉所有命令行窗口重新打开（让 PATH 生效）。
  3. 回到「方式一」的 4 条命令，逐条执行。

3方式三：官方源（不依赖国内镜像）

国内镜像偶尔同步滞后导致缺包时，可直接走 OpenAI 官方 npm 源（需网络能连 registry.npmjs.org，必要时挂代理）：

npm install -g @openai/codex --include=optional
codex --version

官方仓库永远是最新、最全的，但国内裸网可能连不上 —— 优先用方式一的镜像源。

4方式四（最省心）：手动下载，点链接就行 ⭐

不想敲命令、上面都嫌麻烦？直接下 OpenAI 官方编译好的现成程序，像下普通软件一样——不用装 Node、不碰 npm、不受国内镜像缺包影响，是装不上时最可靠的退路。

第 1 步 · 下载（约 99MB，二选一，国内首选第一个）：

⬇ 阿里云国内直链（推荐 · 5MB/s） GitHub 官方 Release（需翻墙）

从 GitHub 下时，在 Assets 列表里找 codex-x86_64-pc-windows-msvc.exe.zip 这个文件点下载。

第 2 步 · 解压：下完得到一个 .zip 压缩包，右键 →「全部解压缩」（或用 360压缩 / 7-Zip 解压）。

第 3 步 · 改名 + 放对位置：

  1. 解压后里面有个 codex-x86_64-pc-windows-msvc.exe，把它改名成 codex.exe（看不到 .exe 后缀也没关系，改成 codex 即可）。
  2. 在文件夹地址栏输入 %USERPROFILE%\bin 回车（没有 bin 文件夹就在用户目录里新建一个名为 bin 的文件夹），把 codex.exe 拖进去。
💡 怎么打开 %USERPROFILE%\bin？ 按 Win+E 开文件资源管理器，在最上面地址栏粘贴 %USERPROFILE%\bin 回车就到了；提示「找不到」就先到 %USERPROFILE%（你的用户文件夹，如 C:\Users\你的名字），右键新建文件夹起名 bin，再进去把 codex.exe 放进来。

第 4 步 · 完成：回到 U-King 点「重新检测」。还认不出就彻底关闭 U-King 再重开（托盘右键退出，再双击 U-King.exe）。

⚠️ 这是 OpenAI 官方原版程序（来自 github.com/openai/codex 官方发布），U-King 只是把它镜像到国内方便下载，没有任何改动，放心用。

5方式五：会用命令的话，一键脚本最快

嫌手动几步麻烦、且会用命令行，在 U-King 内置终端或 PowerShell 里粘贴回车，自动下载 + 解压 + 装好（等价于方式四的全过程）：

# 下官方二进制(国内阿里云镜像→GitHub官方 两路)，解压装到 用户目录\bin\codex.exe
powershell -Command "$d=$env:USERPROFILE+'\bin'; New-Item -ItemType Directory -Force $d | Out-Null; $z=$env:TEMP+'\codex.zip'; try { Invoke-WebRequest -UseBasicParsing 'https://u-claw-updates.oss-cn-shenzhen.aliyuncs.com/uking/runtimes/codex-win-x64.zip' -OutFile $z } catch { Invoke-WebRequest -UseBasicParsing 'https://github.com/openai/codex/releases/latest/download/codex-x86_64-pc-windows-msvc.exe.zip' -OutFile $z }; Expand-Archive -Force $z ($env:TEMP+'\codexcli'); Copy-Item -Force ($env:TEMP+'\codexcli\codex-x86_64-pc-windows-msvc.exe') ($d+'\codex.exe'); & ($d+'\codex.exe') --version"

最后打印出版本号就成功 ✅。回 U-King 点「重新检测」即可。

❓ 常见问题

codex 装上了，运行却报错 / 闪退？
先重装主包并强制包含可选依赖：
npm install -g @openai/codex --registry=https://registry.npmmirror.com --include=optional
再 codex --version 验证。还不行就走「方式四」下载官方二进制，避开 npm。
npm 报 ETIMEDOUT / 一直卡住不动？
多半是客户机装了代理（clash / v2ray）把 npm 拦死。先跑方式一的第 1 步清代理；还不行就 npm cache clean --force 清缓存后重试。
提示「无法加载 codex.ps1，因为在此系统上禁止运行脚本」？
PowerShell 默认禁脚本。免管理员放开一次即可（只对当前用户）：
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
提示确认时输入 Y 回车。或者改用 CMD（命令提示符）敲 codex。
装好了，U-King 还是说没装？
命令行里 codex --version 能打印版本号才算真装好。确认后回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 再重新打开（右下角托盘图标 → 退出，再双击 U-King.exe）。
装完后怎么用？要登录 OpenAI 吗？
不用登录 OpenAI。 U-King 已经帮你把底层 API 指向了国内可用的虾盘云驱动。终端里直接敲 codex 就能开聊，额度由 U-King 的虾盘云提供（在「AI 设置」里可查余额、充值）。
