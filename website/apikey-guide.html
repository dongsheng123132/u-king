🧭通用四步（每家都一样）
  1. 注册账号 —— 打开对应平台，用手机号注册 / 登录。
  2. 实名认证（重点！） —— 国内平台基本都要先实名（身份证 / 支付宝刷脸）才肯发 Key。没实名 = 拿不到 Key、调不通模型，这一步绕不过去，先做完它。
  3. 申请 Key —— 进「API Key / 密钥」页，点【创建】，复制那串 sk-（多半只显示一次，立刻存好）。多数平台还要账户里有余额或领免费额度才能用。
  4. 粘贴使用 —— 回 ClawX「模型设置」（或 U-King「AI 设置」）选对应服务商，把 Key 粘进去保存。它会记住，下次直接用，作图 / 视频 / 写作都走这个 Key。
