工具实战 · Codex / 龙虾 / Hermes

上一课我们玩透了 Claude Code。但 U-King 管家里其实装了一整套 AI 工具，常用的有三个："Codex"、"ClawX 龙虾"、"Hermes"。很多新手一打开就懵了——这么多东西，我到底该点哪个？

别慌。这一课我用大白话把这三个工具讲清楚：各自是什么、什么场景用哪个、怎么上手、怎么接上虾盘云让它们能干活。看完你就再也不会选错了。

一句话先记住：不会写代码、就想聊天办事 → 用龙虾；想让 AI 帮你写程序、改代码 → 用 Codex 或 Claude Code；想让 AI 自动跑一长串任务、当个小机器人 → 用 Hermes。

一、Codex —— OpenAI 出的"编程专家"

Codex（读作"扣-代克斯"）是 OpenAI 公司（也就是 ChatGPT 的东家）专门做编程的工具。你可以把它想象成一个只会用 GPT 大脑的程序员助手。

它能干什么

  • 帮你写代码、改 bug、解释别人的代码；
  • 你用大白话说"帮我做个抽奖小程序"，它就一行行把代码敲出来；
  • 有两种用法：CLI 命令行版（在黑窗口里打字指挥）和桌面版（有图形界面，点点点）。
重要：Codex 只支持 GPT 系列模型（GPT-5、GPT-4 这一家）。它不能用 Claude、不能用国产模型。所以如果你特别想用 GPT 的脑子写代码，就选它。

它和 Claude Code 有啥区别

很简单：Codex 用的是 OpenAI 的 GPT 脑子，Claude Code 用的是 Anthropic 的 Claude 脑子。用法和体验很像，都是命令行里跟 AI 对话写代码。哪个顺手用哪个，也可以两个都装，换着用对比效果。

怎么安装 + 配虾盘云驱动

最省心的办法：打开 U-King 管家，在工具列表里找到 Codex，点"安装"。管家会自动帮你下载好，并且把"虾盘云驱动"配好——也就是让 Codex 走国内中转、充值就能用，不用你自己去折腾科学上网或者填一堆 API 配置。

更详细的图文步骤，请看 U 盘里附带的 《Codex 安装说明》 文档，里面有每一步的截图，照着点就行。

装好后，在 U-King 管家里点"打开 Codex"，第一次它会问你授权登录，按提示走完就行。然后就能像这样跟它说话：

codex "帮我写一个 Python 脚本，把这个文件夹里所有图片压缩一半"

它就会开始动手，过程中会问你要不要执行某条命令，你看着没问题就回车确认。

二、ClawX 龙虾 —— 小白首选的"聊天助手"

如果你完全不懂代码，只想要一个像微信一样、打字就能聊、聊着聊着事就办了的 AI——那 ClawX（中文叫"龙虾"）就是为你准备的。它是图形化界面，不需要敲任何命令，鼠标点点、键盘打字就行。

龙虾能帮你做什么

  • 问知识：写文案、改简历、翻译、写邮件、做计划表；
  • 办事情：整理桌面文件、批量改文件名、读一份 PDF 帮你总结；
  • 就像跟一个无所不知的朋友发消息——你说人话，它办事。
小白第一次用 AI，强烈建议从龙虾开始。没有任何门槛，会打字、会发微信，就会用它。

基础操作（三步走）

  1. 在 U-King 管家里找到 ClawX 龙虾，点"安装"，再点"打开"；
  2. 界面就是一个聊天框，跟微信一模一样。在最下面的输入框里打字，回车发送；
  3. 比如你打："帮我写一段朋友圈文案，主题是周末去爬山，要轻松一点。" 它马上就给你回。觉得不满意，就接着说"再短一点""加点幽默"，它会改。

怎么接虾盘云

龙虾的驱动同样由 U-King 管家自动配好。你要做的只有一件事：充值。到 cloud.u-claw.org 给你的卡密充值（¥10 起步），充完龙虾就能正常聊天了。如果它回你"额度不足""token 无效"，八成就是还没充值或余额用光了，去充一下即可。

三、Hermes —— 进阶的"自动跑腿 Agent"

Hermes（读作"赫尔墨斯"，是希腊神话里跑腿送信的神）是一个更高级的 AI Agent（智能体）。"Agent"你就理解成一个能自己连续干一长串活、中途不用你一直盯着的小机器人。

它和龙虾、Codex 有啥不一样

龙虾是你问一句它答一句；Hermes 更像你交给它一个大任务，它自己拆解成很多小步骤，一步步自动跑完。比如"帮我把这个文件夹里 100 张图片都加上水印、改好名字、再分类放进不同文件夹"——它会自己规划、自己执行。

Hermes 偏进阶、偏自动化。如果你刚入门、还没玩熟龙虾，可以先放着，等用顺手了再来碰它。它真正的威力在于"无人值守地批量干活"。

基础操作

  1. 在 U-King 管家里安装并打开 Hermes；
  2. 第一次打开会让你选/配一个模型（驱动也是管家配好的，走虾盘云）；
  3. 给它下一个明确的任务指令，越具体越好，然后让它自己跑。
给 Agent 下任务时，涉及"删除""覆盖"这类操作一定要说清楚、说保守。它真的会照做，删错了不好恢复。先拿不重要的文件夹练手。

五、三个工具的共同点：都靠虾盘云"加油"

不管你用哪个，它们底层都接的是同一个东西——虾盘云中转。好处是：国内直连，不用科学上网；充值即用，¥10 起；不用自己注册 OpenAI 账号、不用绑卡。

  • 驱动配置：U-King 管家在你装工具时自动搞定，你不用碰；
  • 你唯一要做的：去 cloud.u-claw.org 给卡密充值；
  • 遇到"额度不足/token 无效"——先想想是不是没充值或余额见底了。
省钱小窍门：聊天、写文案这类轻任务很便宜，¥10 能用很久。写大段代码、跑 Hermes 自动任务会快一些，按需充值即可。
