一、AI 到底能帮普通人做什么

很多人觉得 AI 是程序员、是科学家才用得上的东西。其实恰恰相反——AI 最擅长的，是帮你处理那些"会做但很烦、很费时间"的活儿。你把它当成一个 24 小时在线、不要工资、还挺机灵的助理就行。下面是几个真实场景，你大概率每天都在干。

1. 写文章 / 写文案

比如你要发个朋友圈卖自家土蜂蜜，憋了半天写不出来。你可以直接对 AI 说：

帮我写 3 条卖土蜂蜜的朋友圈文案，
要接地气、像朋友推荐，不要太像广告，每条 50 字以内。

几秒钟它就给你三条，你挑一条改改就能发。请假条、道歉信、给孩子写的家长寄语、年终总结……同理。

2. 做表格 / 整理数据

你有一堆乱七八糟的客户记录，想整理成一张干净的表格。或者你想要一份"家庭月度开支模板"。直接说："帮我做一个 Excel 表格，记录每个月房租、水电、伙食、孩子学费，最后能自动算总和。"它会给你结构，甚至给你能直接用的公式。

3. 出方案 / 出主意

下周朋友过生日，预算 500，4 个人，想找个有意思的玩法。问 AI："帮我策划一个 4 人、预算 500 元的生日聚会方案，列出流程、买什么、大概花多少钱。"它会给你一份带时间和花销的清单。装修、旅游路线、开店选址，都能这么问。

4. 写代码 / 做小工具

这条专门给"想试试又怕难"的人。你哪怕一行代码都不会，也可以说："帮我写一个网页，能把我输入的一段中文翻译成拼音，要有个大输入框和一个按钮。"AI 会把代码写好，你复制粘贴就能用。这正是 U-King 里 Claude Code、Codex 这些工具的拿手好戏。

5. 做自媒体 / 短视频

想做抖音、小红书但没思路？"帮我想 10 个适合新手宝妈做的小红书选题，每个配一句吸引人的标题。"它能给选题、写脚本、起标题、想标签，把你从"不知道发啥"里救出来。

记住一句话：你平时怎么跟一个聪明的同事交代任务，就怎么跟 AI 说话。说清楚"要什么、给谁看、什么风格、多长"，结果就好。这一点我们后面在《提示词》那课会专门教。

二、U-King 装好后，界面长啥样、该点哪

U-King 是一个"AI 管家"。它的作用很简单：帮你把好用的 AI 工具一键装好、配好，你不用去折腾那些复杂的安装和设置。它会帮你装这几样东西：

  • Claude Code —— 写代码、做小工具最强，在黑色命令行窗口里用。
  • Codex —— 另一个写代码的好手，和 Claude Code 二选一或都装。
  • ClawX（龙虾） —— 带聊天界面的 AI 助手，像微信一样有对话框，最适合新手。
  • Hermes —— 本地 AI 小助手，能帮你自动跑一些任务。

打开 U-King，你会看到一个干净的主界面，上面就是这几个工具的卡片，每个旁边有一个"安装"或"启动"按钮。你要做的就三步：

  1. 挑一个工具。完全没用过，就先点 ClawX（龙虾），它有聊天框，最像你熟悉的微信。
  2. 点"安装"，然后等进度条走完。这一步它在后台帮你下载和配置，你喝口水就行。
  3. 点"启动"，工具就打开了。第一次它可能让你确认一下，跟着提示点"下一步"即可。
第一次启动如果提示"额度不足 / Invalid token / 余额不足"，别慌——这不是坏了，是你还没充值。往下看第三节就明白了。

三、虾盘云中转是什么（一句话听懂）

这是新手最容易卡住、也最容易被吓到的地方，但其实特别简单。

你可以把它理解成：一个"国内能直接连上的 AI 入口"。

为什么需要它？因为很多最强的 AI（比如 Claude、GPT）服务器在国外，国内网络直接连经常连不上、要排队、要搞代理，普通人根本搞不定。虾盘云中转就是架在中间的一座桥：你的 U-King 连虾盘云，虾盘云替你连国外的 AI，再把结果送回来。你这边感觉就是"直接、稳、快"。

一句话：充值即用，国内直连，不用懂任何技术，也不用翻墙。

它怎么收费？按用量，最低 ¥10 就能起步，用多少扣多少，像手机话费一样。充值入口在 U-King 里或对应的充值页面，扫码付款，余额马上到账，然后回去再点"启动"就能正常聊天了。

  • 不用懂"API""token"这些词，你只要记得："余额够，就能用。"
  • 余额是你自己的，用完了再充，不强制包月。
  • 第一次建议先充 ¥10 试水，跑顺了再说。
