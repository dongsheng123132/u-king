工具实战 · Claude Code

这一课我们认识 AI 编程界的「扛把子」——Claude Code。名字里有个 Code（代码），听起来像程序员专属，但其实它是个能帮你读懂一整个项目、自己动手改文件、自己跑命令的 AI 助手。哪怕你一行代码都不会，看完这一课也能让它帮你干活。

一句话先记住：Claude Code 是一个住在「终端」里的 AI。你用大白话跟它说要干嘛，它就自己去看文件、写文件、改 bug，干完还告诉你它做了啥。

一、它是什么？适合谁？

你之前用的网页版 AI（比如聊天框）有个毛病：它看不到你电脑里的文件，你得手动把代码复制进去、再把它的回复复制出来，来回搬运累死人。

Claude Code 不一样。它直接「住」在你电脑里，能：

  • 看——自己翻你整个项目文件夹，搞清楚来龙去脉；
  • 写——直接帮你新建、修改文件，不用你复制粘贴；
  • 跑——自己执行命令（比如安装依赖、运行程序、查报错）；
  • 改 bug——你说「程序报错了」，它能自己去找原因、改好、再验证一遍。

谁适合用它？

  • 想学编程但卡在「环境装不上」「报错看不懂」的新手；
  • 有个小项目（网站、脚本、小工具）想让 AI 帮忙搭起来或改一改；
  • 程序员想提速，把脏活累活丢给 AI。
要点：Claude Code 最大的价值不是「写出几行代码」，而是它能把整件事从头到尾包圆——你提需求，它读、写、跑、验证一条龙，你只负责点头或纠正。

Claude Code 是在「终端」（一个黑底白字、专门敲命令的窗口）里运行的。很多新手卡在这一步：自己打开的终端往往「找不到命令」，敲 claude 提示「不是内部或外部命令」。

三、你的第一个任务：让它读项目 + 改个 bug

从 U-King 点「打开终端」后，先用 cd 命令进到你的项目文件夹。比如你的项目在桌面的 myapp 文件夹：

cd Desktop/myapp

然后启动 Claude Code，直接敲：

claude

它会进入对话模式（下面会出现一个让你打字的输入框）。现在你就能用大白话给它派活了。第一个任务，建议先让它「看一眼」你的项目：

这是个什么项目？帮我用一句话讲清楚它是干嘛的，
还有主要文件都放在哪。

它会自己去翻文件夹，几秒后给你一份「人话版」的项目说明。这一步很重要——它读懂了，后面才改得对。

接着让它改 bug。假设你跑程序时报了个错，把报错信息原封不动复制给它：

我运行的时候报这个错（把报错粘进来），
帮我找原因、改好，然后再跑一遍确认没问题。

Claude Code 会：① 看相关文件 → ② 判断哪里错了 → ③ 改掉 → ④ 自己跑一遍验证。每改一处文件，它都会问你「能改吗」，你看一眼觉得 OK 就回 yes（或回车同意）。

要点：不会写代码完全没关系。你只要会两件事——把报错原文给它、对它的修改说同意还是不同意。剩下的它全包。

四、常用操作（记这几个就够）

  • 派活：直接打字说你想干嘛，越具体越好。例：「把首页标题改成『欢迎光临』，字大一点」。
  • 同意修改：它问你要不要改文件时，回 yes 或回车。
  • 拒绝/纠正：觉得不对就直接说「不对，我是想要……」，它会重来。
  • 退出：敲 /exit，或按两下 Ctrl + C。
  • 清空重来：聊跑偏了，敲 /clear 开个干净的话题。
  • 看它能干啥：敲 /help 列出所有命令。
说人话技巧：把它当一个很聪明但刚来的新同事。交代任务时说清「要什么结果、在哪个文件、有什么限制」，比甩一句「优化一下」管用十倍。

五、进阶入门：记忆 与 技能

记忆（Memory）——让它记住你的偏好

你不想每次都重复交代「这个项目用中文注释」「别动 config 文件」之类的规矩。Claude Code 支持在项目里放一个叫 CLAUDE.md 的文件，把这些「项目须知」写进去，它每次都会自动读。

最省事的办法：在对话里敲 /init，它会自己逛一圈项目、生成一份 CLAUDE.md 草稿。你也可以直接对它说：

把"所有回复用中文、代码注释也用中文"
记到项目的 CLAUDE.md 里。

以后无论谁来用这个项目，Claude Code 都会按这份「家规」办事。

技能（Skills）——给它装「专项本领」

技能就像给 AI 装的一个个「外挂小本领」：比如「做 PPT」「处理 Excel」「按公司模板写文档」。装上对应技能后，你说一句「帮我把这份数据做成表格」，它就知道该怎么专业地干，而不是瞎猜。

新手现在不用急着自己做技能。先知道有这么个东西、它能让 AI 变更专业就行。等你用熟了，再去研究怎么加自己的技能。

记忆 vs 技能：记忆是「这个项目的规矩」（每次自动读）；技能是「一项可复用的本领」（需要时调用）。新手先用好记忆（CLAUDE.md），技能慢慢来。

六、中国用户的真实坑 & 解法

这些是国内用户最常踩的，挨个对照解决：

坑 1：连不上 / 一直转圈 / 报网络错

原因：默认连的是国外服务器，被墙了。
解法：用 U-King 一键安装，它默认接虾盘云国内中转，直连可用。别自己瞎配国外地址。

坑 2：提示「余额不足」「Token 用完了」

原因：AI 按用量计费，你的虾盘云账户没钱了。
解法：去充值（¥10 起，扫码即到账），用量大就多充点。日常聊聊改改，¥10 能用挺久。

坑 3：敲 claude 提示「不是内部或外部命令」

原因：你用的是没配好环境的终端，找不到 Claude Code。
解法：永远从 U-King 工具卡点「打开终端」，别用系统自带命令行。这是本课反复强调的重点。

坑 4：Node 环境冲突 / 版本不对

原因：你电脑里可能装过别的 Node，版本太老或打架。
解法：U-King 自带独立 Node，不跟你系统的混用。只要从 U-King 的终端启动，就用的是它配好的那一套，不会冲突。

坑 5：中文路径 / 带空格的文件夹出错

原因：项目放在像「我的 文档/新建 文件夹」这种带中文、带空格的路径下，有些命令会犯迷糊。
解法：把项目放在纯英文、没空格的路径，比如 D:\code\myapp。这是个一劳永逸的好习惯。

别把项目放在 C 盘的「桌面」深处或一堆中文文件夹里。新建一个 D:\code\，所有项目都丢这儿，少很多莫名其妙的报错。
