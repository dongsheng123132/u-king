工具速查卡

这一页就是你的"作弊小抄"。不用从头读，遇到事的时候按 Ctrl+F（在网页里按住 Ctrl 再按 F，就会弹出搜索框）打几个字，直接跳到你要的那一行。建议收藏，用的时候扫一眼就走。

先记住一个大前提：下面这些工具（Claude Code、Codex、ClawX 龙虾、Hermes）都是 U-King AI 管家 帮你一键装好的，底层都接的是虾盘云中转——国内直接连得上，充值（¥10 起）就能用，不用翻墙、不用自己折腾 API。所以你只管用命令，钱和网络的事 U-King 都替你搞定了。

一、Claude Code 常用（写代码 / 干活最强的那个）

Claude Code 是个在终端（黑底白字的命令窗口）里跑的 AI。打开终端，输入 claude 回车就进去了，然后直接拿中文跟它说话。下面是进去之后最常用的操作：

你想干什么怎么操作
启动它终端里输入 claude 回车
跟它说话直接打中文，比如"帮我写个登录页面"，回车
让它读某个文件消息里打 @ 然后选文件名（如 @index.html）
清空对话重新开始输入 /clear
查看所有快捷命令输入 /help
撤销它刚才改的东西输入 /undo
换个 AI 模型输入 /model 再选
退出输入 /exit，或连按两次 Ctrl+C
小技巧：让它干一件大事的时候，把要求写清楚点（"用 Python、加注释、最后告诉我怎么运行"），它干得又快又准。说得越含糊，返工越多。

二、Codex 常用（OpenAI 出的另一个代码 AI）

Codex 用法和 Claude Code 几乎一模一样，也是终端里输入 codex 回车进去，然后中文对话。两者你随便用哪个都行，习惯了一个就行。

你想干什么怎么操作
启动它终端里输入 codex 回车
带一句话直接开干codex "帮我把这个文件夹的图片改成 jpg"
让它自动执行不用每步确认启动加参数 codex --full-auto（放手让它干，新手先别用）
退出按 Ctrl+C 两次
提醒：--full-auto（全自动）模式它会自己删文件、自己运行命令，不再问你。重要资料先备份，确认它干的事你看得懂了，再开这个模式。

三、ClawX 龙虾 常用（带界面的 AI 助手）

ClawX（俗称"龙虾"）不用打命令，它是个有窗口、能点的图形界面，适合不爱碰终端的人。双击桌面图标打开就行。

你想干什么怎么操作
打开龙虾双击桌面 ClawX / 龙虾 图标
开始聊天下面的输入框打字，回车发送
新建一个对话点左上角"＋ 新对话"
发图片 / 文件给它看点输入框旁边的 📎 回形针，选文件
换模型点对话框顶部的模型名字，下拉选择
看历史对话左侧边栏，点对应标题
打开设置左下角 ⚙ 齿轮图标
要点：龙虾、Claude Code、Codex 用的是同一个账户、同一笔余额（都走虾盘云）。在哪个工具里花钱，扣的都是同一个池子，所以充一次值，三个工具都能用。

四、U-King 里：切模型 / 充值 / 打开终端

U-King 是那个总管的"AI 管家"主界面，装工具、配置、充值都在它里面。下面三件事最常被问：

① 怎么切换模型

  1. 打开 U-King 主界面
  2. 找到「模型」或「设置」里的模型选择
  3. 下拉列表里选一个（比如便宜快的国产模型，或更聪明的旗舰模型）
  4. 选完即生效，下次对话就用新模型
不知道选哪个？日常聊天 / 写文案就用默认的国产模型，又快又省钱；写复杂代码、要它动脑子的活，再换更强的模型。

② 怎么充值

  1. 打开 U-King，找到「充值」/「余额」入口
  2. 点进去会跳到充值页面，最低 ¥10 起
  3. 扫码付款（微信 / 支付宝），到账即用，不用填任何 API Key
  4. 充完回到工具，余额会自动更新，直接接着用
充值是按用量扣费的，不是包月。¥10 够普通人用挺久，用完了再充就行，不会自动续费。

③ 怎么打开终端（运行 claude / codex 的那个黑窗口）

很多命令要在"终端"里敲，新手常常找不到它在哪。最省事的办法：

方式步骤
U-King 里直接开（推荐）U-King 界面里点「打开终端」/「命令行」按钮，它会自动开好、环境也配好
Windows 自己开按 Win 键，输入 cmd 或 终端，回车
在某个文件夹里开进那个文件夹，地址栏输入 cmd 回车，就在这个位置打开了
为什么推荐用 U-King 里的"打开终端"？因为它已经帮你把 claude、codex 这些命令配好了路径。自己开的 cmd 有时会提示"不是内部或外部命令"——那就是路径没配上，用 U-King 开的就没这问题。
