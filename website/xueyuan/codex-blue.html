📘 Codex CLI 蓝皮书 · 安装配置入门

目标：从没听过 Codex，到在自己电脑上敲一句中文让它帮你写代码。全程不用登录 OpenAI、不用翻墙。

最省事的路：直接下 U-King 一键装（帮你装好 Codex + 接好国内算力，跳过下面所有命令）。下面是想自己动手 / U-King 装不上时的完整手册。

一、Codex 是什么，能干嘛

Codex CLI 是 OpenAI 官方的命令行 AI 编程助手。装好后在终端敲 codex，就能用大白话指挥它：

  • 「帮我写个 Python 脚本，把这个文件夹里的图片批量压缩」
  • 「这段代码报错了，帮我看看哪里错了并改好」
  • 「给这个项目加一个登录页面」
  • 「把这个 Excel 里的数据读出来生成图表」

它能读你的文件、写代码、跑命令、自己改自己跑，是目前最强的"AI 程序员"之一。和网页版 ChatGPT 的区别：它直接在你电脑上动手干活，而不只是聊天。

⚠️ 国内用的最大坑：Codex 的运行内核是平台原生二进制。新版 @openai/codex 已把它打进主包，别再单独装旧的 @openai/codex-win32-x64（可能 404）。国内镜像滞后或代理抖动时，npm 仍可能跳过可选二进制，所以下面命令带 --include=optional；还不行就走「方式四」免 npm。

二、安装：5 种装法，从懒到勤

🥇 最推荐：用 U-King 一键装——它的内置终端已配好便携 Node + 国内镜像，点一下就好，下面的坑它都帮你填了。以下是手动方案。

方式一（最推荐手动法）：在命令行里装

在 U-King 内置终端，或系统的 PowerShell / CMD 里，逐条复制粘贴回车：

# 1) 清掉可能写死的代理（客户机的 clash/v2ray 常把 npm 拦死）
npm config delete proxy --location=global
npm config delete https-proxy --location=global

# 2) 装 Codex CLI 主包（国内镜像，--include=optional 强制拉平台二进制）
npm install -g @openai/codex --registry=https://registry.npmmirror.com --include=optional

# 3) 验证：能打印版本号就成功了
codex --version

最后一条能打印出版本号（类似 codex-cli 0.1xx.x）就装好了 ✅。

💡 敲 npm 提示「不是内部或外部命令」？说明缺 Node.js，看方式二。

方式二：先装 Node.js

  • Node.js 官网下载，或 国内镜像直链 v22 Windows x64
  • 选 LTS 长期支持版（Windows 选 .msi），双击一路下一步。
  • 关掉所有命令行窗口重开（让 PATH 生效），再回方式一执行。

方式三：官方源（不依赖国内镜像）

国内镜像偶尔同步滞后缺包时，走官方源（需能连 registry.npmjs.org，必要时挂代理）：

npm install -g @openai/codex --include=optional
codex --version

方式四（最省心 · 零命令）⭐：手动下现成程序

不想敲命令？直接下 OpenAI 官方编译好的现成 exe，像下普通软件一样——不装 Node、不碰 npm、不受镜像缺包影响，是装不上时最可靠的退路。

  1. 下载（约 99MB，二选一，国内首选第一个）：
    • 阿里云国内直链（推荐）
    • GitHub 官方 Release（需翻墙） —— 在 Assets 里找 codex-x86_64-pc-windows-msvc.exe.zip
  2. 解压：右键「全部解压缩」（或 7-Zip / 360压缩）。
  3. 改名 + 放对位置：把解压出的 codex-x86_64-pc-windows-msvc.exe 改名成 codex.exe，放进 %USERPROFILE%\bin（没有 bin 文件夹就在用户目录里新建一个）。

    怎么打开？按 Win+E，地址栏粘贴 %USERPROFILE%\bin 回车即到；找不到就先到 %USERPROFILE% 新建 bin 文件夹再进去。

  4. 完成：回 U-King 点「重新检测」，认不出就彻底重开 U-King。

⚠️ 这是 OpenAI 官方原版程序（来自 github.com/openai/codex），U-King 只是镜像到国内方便下载，无任何改动。

方式五：会用命令的话，一键脚本最快

在终端粘贴回车，自动下载 + 解压 + 装好（等价方式四全过程）：

powershell -Command "$d=$env:USERPROFILE+'\bin'; New-Item -ItemType Directory -Force $d | Out-Null; $z=$env:TEMP+'\codex.zip'; try { Invoke-WebRequest -UseBasicParsing 'https://u-claw-updates.oss-cn-shenzhen.aliyuncs.com/uking/runtimes/codex-win-x64.zip' -OutFile $z } catch { Invoke-WebRequest -UseBasicParsing 'https://github.com/openai/codex/releases/latest/download/codex-x86_64-pc-windows-msvc.exe.zip' -OutFile $z }; Expand-Archive -Force $z ($env:TEMP+'\codexcli'); Copy-Item -Force ($env:TEMP+'\codexcli\codex-x86_64-pc-windows-msvc.exe') ($d+'\codex.exe'); & ($d+'\codex.exe') --version"

打开终端（U-King 内置终端，或系统 PowerShell），进到任意一个文件夹，敲：

五、常见报错 TOP5

1. codex 装上了，运行却报错 / 闪退？

先重装主包并强制包含可选依赖：

npm install -g @openai/codex --registry=https://registry.npmmirror.com --include=optional

再 codex --version 验证。还不行就用「方式四」免 npm 下载官方二进制。

2. npm 报 ETIMEDOUT / 一直卡住不动？

多半是客户机装了代理（clash / v2ray）把 npm 拦死。先跑方式一第 1 步清代理；还不行 npm cache clean --force 清缓存重试。

3. 提示「无法加载 codex.ps1，因为在此系统上禁止运行脚本」？

PowerShell 默认禁脚本。免管理员放开一次（只对当前用户）：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

提示确认时输入 Y 回车。或改用 CMD 敲 codex。

4. 装好了，U-King 还说没装？

命令行里 codex --version 能打印版本号才算真装好。确认后回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 再重开（托盘右键退出 → 双击 U-King.exe）。

5. 装完后怎么用？要登录 OpenAI 吗？

不用登录 OpenAI。 U-King 已把底层 API 指向国内可用的虾盘云驱动。终端直接敲 codex 就能开聊，额度由虾盘云提供（「AI 设置」可查余额、充值）。
