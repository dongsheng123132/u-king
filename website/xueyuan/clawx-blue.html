📘 ClawX 蓝皮书 · 安装配置入门

目标：从没听过 ClawX，到在自己电脑上打开它，像聊天一样说一句话就让它帮你干活。全程不用敲命令、不用翻墙。

最省事的路：直接下 U-King 一键装（帮你装好 ClawX + 接好国内算力，跳过下面所有步骤）。下面是想自己动手 / U-King 装不上时的完整手册。

一、ClawX 是什么，能干嘛

ClawX 是一款图形界面的全能 AI 助手——底层是开源的 OpenClaw，外面套了个像聊天软件一样的窗口。打开它就是一个对话框，你像发微信一样跟它说话，它就照着做：

  • 「帮我把这份资料总结成 5 条要点」
  • 「画一张赛博朋克风格的猫，竖版海报」
  • 「把这段故事改成 4 格漫画的分镜脚本」
  • 「读一下这个 PDF，告诉我合同里有没有坑」
  • 「写一篇介绍我家奶茶店的公众号推文」

它能对话、作图、写作、读文件、多模态（图文音视频都能聊），还能装「技能」干各种专项活（做视频、画漫画、写小说、编程……）。和网页版 ChatGPT 的区别：它装在你电脑上、能读你的本地文件、能装技能扩展能力，而且接的是国内可用的模型，不用翻墙。

🥇 为什么新手先用它？ ClawX 是这一套 AI 工具里最不需要技术门槛的一个——会用微信就会用。Codex / Claude Code 那些要在黑乎乎的终端里敲命令，ClawX 全程点点鼠标、打打字就行。先用它把 AI 跑起来、找到感觉，再去碰命令行的工具最顺。

二、安装：一键装 / 官网下载

🥇 最推荐：用 U-King 一键装——它的「工具中心」点一下 ClawX 卡片，自动下载安装、自动接好国内驱动，下面的坑它都帮你填了。以下是手动方案。

方式一（最推荐）：U-King 一键装

  1. 打开 U-King，进**「工具中心 / 我的 AI」**，找到 ClawX 卡片。
  2. 点【一键安装】，它会自动从国内源下载安装包并装好，驱动也自动配好。
  3. 装完点【打开 ClawX】。★第一次打开会弹防火墙窗口，见下面第三节，一定要点【允许访问】。

方式二：从官网下载安装包

不想用 U-King 自动装、想自己下一个安装包的：

  1. 打开 u-king.org，进下载页找 ClawX 安装包（约 100MB+）。
  2. 下完 ClawX-x.x.x-win-x64.exe，双击运行，一路点【下一步】。
  3. 若 Windows 提示「Windows 已保护你的电脑」，点【更多信息】→【仍要运行】（绿色软件未签名，正常现象，不是病毒）。
  4. 装完打开 ClawX，回 U-King 点「重新检测」即可识别。

💡 杀软（360 / 火绒）误拦安装包？把它加白名单，或先关一下杀毒软件再装。装完记得重新打开。

三、★ 第一次打开必看：允许访问网络（最关键的一步）

这一步没做对，ClawX 一定连不上 AI、一直转圈。新手九成的"打不开"都卡在这里，务必看完。

ClawX 要联网才能和大模型对话。第一次打开时，Windows 自带的防火墙第一次见到它，会弹出一个窗口问你「是否允许它访问网络」。

你会看到这样一个窗口（示意）

┌─────────────────────────────────────────┐
│ 🛡️ Windows 安全中心警报                   │
├─────────────────────────────────────────┤
│ Windows Defender 防火墙已阻止此应用的部分功能 │
│ 名称：ClawX                                │
│                                           │
│ ☑ 专用网络（家庭或工作网络）                 │
│ ☑ 公用网络（机场、咖啡馆等）—— 两个都勾上更稳  │
├─────────────────────────────────────────┤
│            [ 取消 ]   [ ✓ 允许访问 ]       │
└─────────────────────────────────────────┘

→ 把上面两个网络都勾上，然后点绿色的【允许访问】。完成！

⚠️ 千万别点「取消」。 点了取消，ClawX 就连不上 AI，会一直转圈或报错。这是正常的安全提示，不是病毒，放行即可。

用 U-King 一键装的，多半不会弹

好消息：用 U-King「一键安装 ClawX」装好的，U-King 已经尽量帮你提前放行了，多数情况根本不会弹这个窗。这一节是给「万一弹出来了」做准备的。

如果手滑点了「取消」怎么补救

二选一：

  1. 最简单：关掉 ClawX，回 U-King 点「打开 ClawX」重启一次，弹窗会再出现，这次点【允许访问】。
  2. 手动放行：Windows 设置 → 搜索「允许应用通过防火墙」→ 找到 ClawX → 把「专用」「公用」都打勾 → 确定。

四、配模型：给 ClawX 接一个"大脑"（不用翻墙）

ClawX 本身只是个"空壳子"，还得给它接一个能用的大模型，它才有脑子、能扣费干活。国内用户别去折腾国外账号——下面两条路任选：

路线 A（推荐 · 免折腾）：虾盘云内置驱动

U-King 自带的 虾盘云 驱动，开箱即用、国内直连、免注册免实名：

  1. U-King「AI 设置」选 虾盘云，它用本机设备 Key 自动配好，无需手填，ClawX 直接能用。
  2. 余额不足点「充值」，扫码即到账。¥1 ≈ 50 万 token，充值/查看余额。

一个 Key 通吃 ClawX 的对话 / 作图 / 写作，不用分别去各家注册、刷脸实名。新手强烈建议先用这个。

路线 B（想用自己的国产 Key）

ClawX 也能指向任何国内大模型。拿到 Key 后，在 ClawX「模型设置」（或 U-King「AI 设置」）选对应服务商、把 sk- 那串粘进去保存即可：

平台 特点 申请页
火山引擎（豆包·即梦） 作图 / 视频最强，新用户常有免费额度 console.volcengine.com/ark
DeepSeek 国内最便宜、速度快，写作/对话够用 platform.deepseek.com
智谱 GLM 常有免费额度 open.bigmodel.cn
Kimi 超长上下文 platform.moonshot.cn

通用四步：注册 → 实名认证（绕不过，先做） → 创建 Key（sk- 开头，多半只显示一次，立刻存好）→ 回 ClawX「模型设置」粘贴保存。想做 AI 作图 / 视频，建议配火山引擎；只想省事就直接用路线 A 的虾盘云。

五、跑通第一个任务：找技能 → 粘贴 → 说需求

ClawX 用起来核心就三件事：找一个「技能」 → 配好「模型 Key」（上一节已做）→ 说一句话让它干活。

先理解一个词：技能 = 一份「教 AI 怎么做某件事」的说明书（比如怎么做视频、怎么画漫画）。配上技能，ClawX 就从"通用助手"变成了"某个专项的高手"。

第 1 步：去技能商店找技能

打开腾讯技能市场 skillhub.cn，手机号注册后，搜你想做的事的关键词（视频 / 作图 / 小说 / 漫画 / 编程 / 写作排版），挑一个现成技能，进详情页把里面的技能内容（提示词 / 配置）复制下来。

第 2 步：把技能粘进 ClawX

回到 ClawX，新建一个对话 / 智能体，把刚复制的技能内容粘进去，让它「记住按这个来做」。不同技能放的位置略有差别，照技能页说明放即可——多数就是直接发给 ClawX，或贴进它的「系统提示 / 技能」栏。

第 3 步：说一句话，开干

像聊天一样跟 ClawX 说你要做什么，例如最简单的试一下：

你好，用一句话介绍下你自己，再帮我画一张「一只举着 U 盘的卡通龙虾」的图。

它会照着技能、用你配的模型一步步做出来。第一次配置花几分钟，以后都是一句话的事。 进阶玩法（技能商店深挖、AI 作图、做自媒体、微信机器人）见 📕 红皮书。

六、常见报错 TOP5

1. ClawX 打开后一直转圈 / 连不上 AI？

九成是网络没放行（第三节那一步）。关掉 ClawX 重开，弹防火墙窗口时点【允许访问】；或手动放行：Windows 设置 → 搜「允许应用通过防火墙」→ 找到 ClawX → 勾「专用」「公用」→ 确定。

2. 能打开，但一发消息就报错 / 说没配模型？

是模型 Key 没配好（第四节）。最省事：U-King「AI 设置」选「虾盘云」自动配好；或在 ClawX「模型设置」里选一家服务商、粘上你的 sk- Key 保存。注意账户得有余额 / 免费额度。

3. 技能粘进去了，AI 却不照着做？

多半是技能粘错位置或没粘全。回技能详情页把内容完整复制（别漏），按技能页说明放对地方（系统提示 / 技能栏）；或开新对话重粘一次。复杂技能记得连同它要求的模型一起配。

4. 双击安装包没反应 / 被拦截？

未签名绿色软件常被 SmartScreen 或杀软（360 / 火绒）误拦。提示「已保护你的电脑」时点【更多信息→仍要运行】；杀软拦截就加白名单或临时关掉再装。还不行就用 U-King「工具中心」让它自动装。

5. 装好了，U-King 还说没装？

ClawX 能正常打开就算装好。回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 再重开（托盘右键退出 → 双击 U-King.exe）。
