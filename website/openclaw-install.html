OpenClaw 龙虾 · 手动安装

命令行版（openclaw）+ 图形版（ClawX）两种，自动装不上时照这里来

OpenClaw 是什么？ 开源的 AI 助手 / 自动化平台。有两种形态：命令行版 openclaw（npm 装，跑在终端）和 图形版 ClawX（桌面 App，点点鼠标就能用）。U-King 已帮你接好国内驱动，装好就能用。

1图形版 ClawX（推荐小白）：直接下安装包

不想碰命令行就装这个。Windows 下 U-King 会优先静默安装；如果被杀软/权限拦住，就按下面按钮手动装：

Windows x64 安装包 Mac Apple Silicon Mac Intel

按钮会自动尝试从 release-info.json 更新到最新版；如果按钮失效，点 最新版清单，复制里面对应系统的下载链接。

  1. 下完 ClawX-x.x.x-win-x64.exe，双击运行。
  2. 若 Windows 提示「已保护你的电脑」，点【更多信息】→【仍要运行】（绿色软件未签名，正常）。
  3. Mac 下打开 .dmg 后，把 ClawX.app 拖到 Applications / 应用程序。
  4. 装完打开 ClawX，回 U-King 点「重新检测」即可识别，驱动会自动配好。

2命令行版 openclaw：U-King 终端里装

需要 Node.js 22.19+（U-King 一般自动装便携版）。在 U-King 终端逐条执行：

# 1) 清代理（客户机 clash/v2ray 常把 npm 拦死）
npm config delete proxy --location=global
npm config delete https-proxy --location=global

# 2) 用国内镜像装 openclaw（绕开官方 git 安装，国内更稳）
npm install -g openclaw --registry=https://registry.npmmirror.com

# 3) 验证
openclaw --version
💡 想在终端里跑起 OpenClaw 网关，命令是 openclaw gateway run --allow-unconfigured（首次必须带 --allow-unconfigured，否则会因没配置而退出）。U-King 的「我的 AI」Dock 点 openclaw 图标会自动带好参数启动。

3方式三：缺 Node.js 先装它

敲 npm 提示「不是内部或外部命令」就先装 Node.js（注意 OpenClaw 要 22.19 以上）：

Node.js 官网 国内镜像直链（v22 · Win x64）

装完关掉命令行窗口重开，再回方式二执行。

❓ 常见问题

ClawX 双击没反应 / 被拦？
未签名绿色软件常被 SmartScreen / 杀软误拦。点【更多信息→仍要运行】，或在杀软里把它加白名单。再不行用「方式二」装命令行版。
openclaw --version 报错 / 提示 Node 版本太低？
OpenClaw 需要 Node 22.19+。装新版 Node（方式三）后重装 openclaw 即可。
启动网关报「gateway already running」？
上次没退干净留了锁文件。删掉它再启：删除 %LOCALAPPDATA%\Temp\openclaw\gateway.*.lock。
装好了，U-King 还说没装？
命令行 openclaw --version 能出版本号、或 ClawX 已经能打开，就算装好。回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 重开。
