Claude Code · 手动安装

自动装不上时，照这个页面在命令行里敲几条命令就能装好

Claude Code 是什么？ Anthropic 官方的命令行 AI 编程助手，通过 npm 安装。U-King 已经帮你接好了国内可用的虾盘云驱动，装好就能直接用，不用登录 Anthropic 官方账号。

1方式一（最推荐）：U-King 内置终端里装

在 U-King 左侧栏打开终端，逐条复制粘贴回车。U-King 的终端已配好便携 Node + 国内镜像：

# 1) 清掉可能写死的代理（客户机的 clash/v2ray 常把 npm 拦死）
npm config delete proxy --location=global
npm config delete https-proxy --location=global

# 2) 用国内镜像装 Claude Code
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

# 3) 验证：能打印版本号就成功了
claude --version

最后一条能打印版本号就装好了 ✅，回 U-King 点「重新检测」。

2方式二：先装 Node.js，再用普通命令行装

若敲 npm 提示「不是内部或外部命令」，说明缺 Node.js。先装它：

Node.js 官网下载 国内镜像直链（v22 · Win x64）

  1. 下 LTS 长期支持版（Windows 选 .msi），一路下一步装完。
  2. 关掉所有命令行窗口重新打开（让 PATH 生效）。
  3. 回到「方式一」的命令逐条执行。

3方式三：官方源（不依赖国内镜像）

国内镜像滞后缺包时，可走官方 npm 源（需能连 registry.npmjs.org，必要时挂代理）：

npm install -g @anthropic-ai/claude-code
claude --version

❓ 常见问题

npm 报 ETIMEDOUT / 一直卡住？
多半是代理（clash/v2ray）把 npm 拦死。先跑方式一第 1 步清代理；还不行 npm cache clean --force 后重试，或临时关掉代理软件。
报「无法加载 claude.ps1，禁止运行脚本」？
PowerShell 默认禁脚本。放开一次（免管理员、仅当前用户）：
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
确认输 Y 回车。或改用 CMD 敲 claude。
装完怎么用？要登录 Anthropic 吗？
不用登录官方。 U-King 已把底层 API 指向国内可用的虾盘云驱动，终端里直接敲 claude 就能用，额度由虾盘云提供（「AI 设置」里查余额/充值）。当然你也可以在「AI 设置」里换成 DeepSeek / 智谱 / Kimi 或你自己的 Key。
装好了，U-King 还说没装？
claude --version 能打印版本号才算真装好。确认后回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 重开。
