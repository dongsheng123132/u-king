Hermes Agent · 手动安装

自动装不上时，照这个页面在命令行里敲几条命令就能装好

Hermes 是什么？ 一个 AI Agent 工具，跟前面几个不同，它是用 Python 的 pip 安装的（不是 npm）。U-King 已帮你接好国内驱动，装好就能用。

1方式一（最推荐）：U-King 内置终端里装

在 U-King 左侧栏打开终端，逐条复制粘贴回车。U-King 终端已配好便携 Python + 国内 pip 源：

# 用阿里云 pip 源装 Hermes（包名是 hermes-agent）
python -m pip install -U hermes-agent -i https://mirrors.aliyun.com/pypi/simple/

# 验证：能打印版本号就成功了
hermes --version

能打印版本号就装好了 ✅，回 U-King 点「重新检测」。

⚠️ 装上了却敲 hermes 找不到命令？ 这是 pip 装的脚本目录（Scripts）没进 PATH。U-King 在内置终端里已自动注入；在系统的 CMD 里则需要：把 Python 的 Scripts 目录加进 PATH，或直接用 python -m hermes 调用。U-King 装机时也会自动帮你把这个目录加进用户 PATH。

2方式二：先装 Python，再用普通命令行装

若敲 python 提示「不是内部或外部命令」，说明缺 Python。装它（务必勾选 Add to PATH）：

Python 官网下载 国内镜像（npmmirror）

  1. 下 3.10 ~ 3.12 版（Windows installer）。
  2. 安装第一屏务必勾上「Add python.exe to PATH」，再点 Install。
  3. 关掉命令行窗口重开，回方式一执行。

3方式三：官方 pip 源（不依赖国内镜像）

国内源滞后缺包时走官方 PyPI（必要时挂代理）：

python -m pip install -U hermes-agent
hermes --version

❓ 常见问题

装完敲 hermes 提示找不到命令？
pip 把可执行脚本装在 Python 的 Scripts 目录，它可能没进 PATH。最稳的办法：在 U-King 内置终端里敲（已自动注入），或用 python -m hermes。也可手动把 ...\Python\Scripts 加进系统环境变量 PATH。
pip 报 SSL / 超时 / 连接错误？
多半是代理或网络。加 -i https://mirrors.aliyun.com/pypi/simple/ 用国内源；有代理就临时关掉，或 pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/。
Hermes 配置在哪？怎么连虾盘云？
Windows 上 Hermes 读 %LOCALAPPDATA%\hermes（不是 ~/.hermes）。U-King 在「AI 设置 → Hermes」里切驱动会自动写好；想自己配就改那个目录下的 config.yaml，把 model 块的 base_url / api_key 填上你的服务商即可。
装好了，U-King 还说没装？
hermes --version 能打印版本号才算真装好。确认后回 U-King 点「重新检测」；还认不出就彻底关闭 U-King 重开。
