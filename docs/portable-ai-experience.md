# U-King 便携 AI 体验规范

> 2026-09-03 定案。适用：USB AI Genie（PicoClaw）、后续 U 盘 OpenClaw、U 盘 ClawX。
> 这是交互与状态边界，不代表三个运行时已经全部实现。

## 一句话规则

**一个 U-King，一套界面，两种入口；用户选择的是“这次使用哪一份 AI”，不是“绿色版还是桌面版”。**

U-King 是唯一的发现、配置、检查、更新和启动界面。PicoClaw、OpenClaw、ClawX 都是可被
U-King 管理的运行时，不各自再造工具市场入口、设置页或聊天壳。

## 两个入口

1. **主入口：`U-King.exe`**。U 盘用户双击它，进入同一套 U-King；从 U 盘运行时，首屏默认选中
   当前盘的「便携 AI」目标。
2. **快捷入口：`启动 AI 精灵.cmd` / 对应运行时启动器**。给熟练用户和救援场景直接打开已就绪的
   AI；它不做安装、配置或更新。终端启动时必须打印运行位置、资料位置、账号来源及“退出后再拔盘”。

桌面快捷方式只是 `U-King.exe` 或本机 AI 的一个**启动方式**，不是“资料放在桌面”的模式。

## 用户看得见的状态模型

每一个运行时实例（PicoClaw、OpenClaw、ClawX）都只有一个目标记录，界面必须同时显示下面三件事：

| 字段 | 本机目标 | U 盘目标 | 调用本机 Claude Code |
| --- | --- | --- | --- |
| 程序在哪运行 | 本机受管理安装目录 | 当前 U 盘的 `U-King\\...` | 当前电脑既有 Claude Code |
| 资料/会话写到哪 | 本机该运行时数据目录 | 当前 U 盘该运行时 `data` / workspace / session / log | 用户选择的项目目录；可为 U 盘项目目录 |
| 账号/凭据来自哪 | 本机配置或本机设备钱包 | 未配置，或用户明确选择“随盘携带” | 当前电脑已有的 Claude 登录或配置 |
| 换电脑后 | 不跟随 | 程序和资料随盘走 | 此电脑没有 Claude Code 即不可用 |

界面绝不使用模糊的“已配置”“已打开”作为唯一状态。每个启动按钮必须带位置，例如：

- `打开 U盘 AI 精灵（KING U盘 · F:）`
- `打开本机 OpenClaw`
- `在 U盘项目中打开本机 Claude Code`

## 页面结构

### 1. 我的 AI：日常启动台

顶部提供**当前使用对象**选择器，不称为版本切换：

```text
当前使用  [这台电脑]  [KING U盘 · F:]
```

选择 U 盘后，展示该盘已准备好的 PicoClaw / OpenClaw / ClawX 卡片；每张卡均展示程序、资料、账号
三行状态，并给出「打开」「AI 设置」「打开资料」「检查与更新」。同一产品同时有本机与 U 盘实例时，
保留两张带明确位置的卡，**不得**默认为上次使用的位置。

「这台电脑上的 AI 工具」区可显示 Claude Code 等宿主机已安装工具，但必须标为快捷调用：

```text
Claude Code · 已安装在这台电脑
使用这台电脑的登录与配置，不会随 U 盘带走
工作目录：F:\\我的项目
[用 Claude Code 打开此目录]
```

本机未安装时直接说明“U 盘 AI 仍可用；Claude Code 不在此电脑”，提供安装入口，不伪装成 U 盘自带。

### 2. U 盘工具盘：制作与维护中心

页面先选目标盘，再选要部署或更新的运行时：PicoClaw（AI 精灵）、OpenClaw、ClawX。它们共用：

- 可移动盘、卷标、空间、文件系统、写保护与就绪状态；
- “不会格式化、不删除其他 U 盘文件”的边界；
- 制作、验证、更新、修复、启动和资料位置；
- 同一套凭据风险提示、移除凭据、丢盘处置说明；
- 同一 Action Core 的目标、版本、状态版本与幂等规则。

运行时各自只提供自己的安装包、运行时清单、配置适配和验证器；不得复制一套 U 盘 UI 或另写一套部署语义。

### 3. 首次使用向导

从 U 盘运行 U-King 且当前盘尚未部署运行时时，默认目标为当前盘，路径为：

```text
盘状态检查 → 选择 AI 运行时 → 选择资料位置（默认此 U 盘）
→ 选择账号策略 → 制作 → 验证 → 打开
```

账号只向用户提供当前技术能够兑现的两种选择：

1. `不在 U 盘保存 AI 账号`：可先制作；联网对话前需在 U-King 中补全账号。
2. `让 AI 账号随 U 盘携带`：凭据和资料都会留在盘内，换电脑可用，但丢盘后必须立即换 Key。

第二项必须勾选确认后才可提交，且有「移除此盘凭据」和「丢盘怎么办」常驻入口。不能承诺尚未实现的
“凭据留在每台电脑、资料随盘且无感可用”第三种模式。

## 经常在家/办公室切换的推荐路径

1. 用户随身携带一块 U 盘：PicoClaw / OpenClaw / ClawX 的可移植运行时及其对应资料都在盘上。
2. 在家或办公室都从 U 盘打开 `U-King.exe`；U-King 自动选择这块盘，并可从「我的 AI」打开盘上的 AI。
3. 日常对话、工作区、会话、日志按运行时隔离并保留在 U 盘；拔盘前先退出对应 AI。
4. 要使用 Claude Code 时，U-King 只检查**当前电脑**是否已装，再用它打开 U 盘上的项目目录；Claude 的登录、
   配置和本机历史仍属于当前电脑，不能随 U 盘迁移。

## 四个防呆闸门

1. 同时存在本机和 U 盘目标时，第一次必须选目标；之后所有按钮仍显示位置，不能静默开错实例。
2. 运行时仍在执行时，提示“退出 AI 后再拔盘”；不把窗口消失当作已安全退出。
3. 更新明确为“只更新此运行时；保留该运行时资料、会话与其他 U 盘文件”。
4. 点击宿主工具（Claude Code 等）前提示“使用本机账号与配置；U-King 只是从所选目录启动它”。

## 分期

- **P1：PicoClaw**：先完成 U 盘 AI 精灵的单一目标卡、设置、验证、启动及直接启动器。
- **P2：OpenClaw、ClawX**：接入同一目标模型和页面骨架；每个运行时须先完成独立的便携落盘取证、
  配置重定向、真实 U 盘验收和许可证清单，不能因 UI 已有就直接复制上盘。

完成判据：用户在任何卡片或启动器前，均可一眼回答“程序在哪运行、资料写到哪、账号来自哪”。
