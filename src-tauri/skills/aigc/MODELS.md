# 模型选型手册（全球最强 · 2026-07）

> 这份是**选型指南**——「哪个活该用哪个模型 + 挂了切谁」。
> **真相源永远是 `node scripts/list-models.mjs`**（实时拉 `/v1/models`，看当前真正能调的）。
> 本文标 ✅=现在就能调、🔜=待服务端加渠道后自动出现在 list-models 里（无需改技能包/发版）。
> 用 `--model <id>` 把首选换成任意 id；**挂了别硬刚同一个，按下面的「替补链」自动降级**。

> ⚠️ `--size` 只填 `宽x高` 像素（`1024x1024`），别填 `16:9`。带字的海报先出背景图再叠字。

## 降级/路由铁律（写进调用逻辑）
1. **默认调该模态首选**；报错先看 `list-models.mjs` 确认模型还在。
2. **上游欠费/5xx/超时** → 按替补链换**下一个模型**（多半换了渠道），别对同一个死重试。
3. **「余额不足」先分清**：是你的虾盘云钱包，还是上游渠道欠费（后者非客户的事，稍后重试或换模型即可）。
4. 海外模型（veo/eleven/suno）走虾盘云 SG 中转，国内客户也能用；能用国产（seedance/kling/海螺/火山）就优先，国内更快更稳。
5. **key 只认虾盘云统一 key**——所有 provider 的真 key 在服务端渠道里，客户端零配置、不外泄。
