# 读文档（uking-office-read）

U-King 的技能包原本**能出不能进**：会生成 Word/Excel/PPT/网页，却读不了用户手上那一份。
这个包补的就是「进」。

## 一句话用法

```bash
python <本技能目录>/scripts/read-doc.py "招标文件.docx" -k "工期,投标保证金,资质,付款"
```

正文打到 **stdout**，统计打到 **stderr** —— 所以可以直接接管道：

```bash
python read-doc.py 合同.pdf -k "违约,付款,期限" | llm "列出所有对我方不利的条款"
```

## 🔴 必须先摘再问，别整份丢进去

真实实测（356KB 的建筑智能化工程招标文件，关键词 `工期,投标保证金,资质,付款`）：

| 做法 | 体积 | 后果 |
|---|---|---|
| 整份转出来直接喂 | 20.9 万字符 ≈ **11.3 万 token** | 131072 的上下文只剩 1.8 万给输出；**每问一句都为整份文件付一次全价** |
| `-k` 本地先摘 | 5.8 万字符 ≈ **3.4 万 token** | 剩 **28%**，答案质量不受影响 |
| `-k` + `-m 14000` 再压 | 1.4 万字符 ≈ **7852 token** | 剩 **7%**，适合只要几个确定字段时 |

问的本来就是「工期/保证金/资质」这几个点，正文其余部分对这个问题就是噪音。
**所以默认就该带 `-k`。** 不带 `-k` 只在「确实要通读全文」时用（比如做全文摘要）。

省多少**取决于关键词有多聚焦**：上面那组词在这份文件里命中几百处，所以只降到 28%；
问得越具体降得越狠。`-m` 是硬上限，用之前想清楚被切掉的部分会不会正是答案所在。

关键词没命中时脚本**不会偷偷回退成全文** —— 它会明说「一次都没命中」。
让用户在不知情的情况下付整份文件的钱，比返回空更糟。

## 支持的格式与转换器

`.docx` `.xlsx` `.pptx` `.pdf` `.csv` `.html` `.txt` 等。

两个转换器，优先 markitdown，pandoc 兜底。同一份 docx 的实测对比：

| | 耗时 | 字符 | ≈token | Markdown 表格行 |
|---|---|---|---|---|
| pandoc 3.10 | 1.8~2.6s | 311,214 | **138,725 → 超过 131072，整份放不进上下文** | 204 |
| **markitdown** | 5.2~6.5s | **209,439（少 33%）** | 113,281（勉强放得下） | **695（多 3.4 倍）** |

pandoc 更快，但输出多三成字符 = 每次调用多付三成 token，表格提取也差一截，
而且这份文件整份转出来**直接超上下文**。
兜底仍然留着 pandoc：它常常已经装了（U-King「厨具工具箱」里就有），而 markitdown 要走 pip。

## 装不上时怎么办

```bash
python -m pip install markitdown[docx,pdf,xlsx]
```

🔴 **必须 `python -m pip`，不能裸跑 `pip`。** 客户机上 `pip` 可能指向别的虚拟环境
（本机实测就指向 Hermes 的 venv，python 3.11），装完 `python`（3.12）那边 `import markitdown`
照样失败 —— 报错完全指不到真因，看起来就像「装了但用不了」。

或者在 U-King 的**厨具工具箱**里装 Pandoc，走兜底路径。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 参数错 / 文件不存在 |
| 3 | 没有任何可用转换器（照上面装一个） |

## 配套技能

读进来之后要**产出**文件，用同包发货的：
`uking-xlsx`（出表格）· `uking-docx`（出 Word）· `uking-ppt`（出 PPT）· `uking-web`（出网页）。

**读完要改他这一份**（而不是另写一份）→ **uking-office-edit**：在原文件上替换文字，样式/页眉页脚/图片字节级不动。用本包把原文读出来，照着原文复制要改的句子，是最不容易白改的做法。
图片和 PDF 的**视觉**理解（看图说话、扫描件）走 `uking-vision`。

## 已知边界（别吹过头）

- **扫描件/图片型 PDF 转不出文字** —— 那是 OCR 的活，走 `uking-vision` 的视觉理解。
- **`.ZBJ` 等招投标专用格式读不了** —— 那是厂商私有格式，需要对应软件导出为 Word/Excel 再读。
- **加密/带权限的文档读不了**，会在 stderr 报出原因。
