# U-King 出真 CAD 图纸（uking-cad）

## 何时用
用户要的是**能拿去用的图纸**（可量取、可再编辑、能给施工/加工看），而不是一张示意插画：
户型图 / 车间布局 / 零件轮廓 / 展位平面 / 管线走向 / 家具排布 / 场地规划。

要的是好看的配图、效果图、渲染图 → 走 `uking-aigc` 作图，不是这里。

## 核心用法
1. 用 write_file 写一份 spec JSON。
2. `node ~/.uking/skills/uking-cad/scripts/gen-dxf.mjs --in 图.json --out 图纸.dxf --json`
3. 输出 `{"ok":true,"file":"…dxf","preview":"…预览.svg","entities":N}`。
   **两个路径都给用户**：dxf 拿去 CAD 里改，预览 svg 直接双击就能看（客户机大多没装 CAD）。

## spec 格式
```json
{
  "title": "两室一厅户型图",
  "layers": [ {"name":"墙体","color":7}, {"name":"标注","color":1}, {"name":"家具","color":5} ],
  "entities": [
    {"type":"rect",     "layer":"墙体", "at":[0,0], "w":9000, "h":6000},
    {"type":"line",     "layer":"墙体", "from":[3600,0], "to":[3600,6000]},
    {"type":"polyline", "layer":"家具", "points":[[200,200],[1800,200],[1800,1000],[200,1000]], "closed":true},
    {"type":"circle",   "layer":"家具", "center":[5000,3000], "r":400},
    {"type":"arc",      "layer":"墙体", "center":[3600,0], "r":800, "start":0, "end":90},
    {"type":"text",     "layer":"标注", "at":[1800,3000], "text":"主卧", "height":300, "align":"center"},
    {"type":"dim",      "layer":"标注", "from":[0,0], "to":[9000,0], "offset":-600, "text":"9000"}
  ]
}
```

图元速查：

| type | 必填 | 说明 |
|---|---|---|
| `line` | `from` `to` | 直线 |
| `rect` | `at` `w` `h` | 矩形（左下角 + 宽高），内部摊成闭合多段线 |
| `polyline` | `points` | 折线；`closed:true` 闭合成多边形 |
| `circle` | `center` `r` | 圆 |
| `arc` | `center` `r` `start` `end` | 圆弧，角度制、逆时针 |
| `text` | `at` `text` | 文字；`height` 字高、`rotation` 角度、`align`(left/center/right) |
| `dim` | `from` `to` | 尺寸标注（尺寸线+界线+箭头+数字）；`offset` 偏移量（负=画在下方/左侧），`text` 不给就自动量长度 |

所有图元都可带 `layer`（不写就是 `0` 层）。`layers` 里没声明的层会自动补上。

## 画图要点（这是本包最值钱的部分）
- **单位就用毫米**：1 图形单位 = 1mm。户型图 9000×6000 = 9 米 × 6 米。别用「米」当单位，
  出图和标注会全部对不上，施工方一眼看出是外行。
- **先定外轮廓再切内部**：`rect` 出总轮廓 → `line` 切隔墙 → 家具/设备 → 最后加 `text` 和 `dim`。
- **分层**：墙体 / 门窗 / 家具 / 标注 至少分开，这是 CAD 图纸的基本规矩，客户拿去能直接关层。
  颜色码：1红 2黄 3绿 4青 5蓝 6紫 7黑白。
- **文字高度按图幅给**：户型图（毫米制、几千单位）字高给 200~300，零件图（几十单位）给 3~5。
  字高给错会出现「一个字盖满全图」或「找不到字在哪」。经验尺子：**字高 ≈ 图幅 / 40**，
  小于图幅 1/300 就等于没标。
  （`dim` 的字高和箭头**不给就按尺寸长度自动算**，所以标注不会出现「小得看不见」；
  但 `text` 图元的 `height` 得你自己给。）
- **尺寸标注至少标总长总宽**：没有尺寸的图纸在工程上不算图纸。
- 尺寸是 `dim` 画出来的线段组合，不是 CAD 的关联标注 —— 客户在 CAD 里拉伸图形，
  数字**不会**跟着变。要跟着变得在 CAD 里重新标一次。**这点如实告诉用户，别让他以为是活标注。**

## 中文
文件按 **UTF-8** 写（中望 / 浩辰 / CAD看图王 / LibreCAD 等现代看图软件都认）。
只有在**老版 AutoCAD 里文字显示成乱码**时，才加 `--encoding escape` —— 它把文字实体写成
`\U+XXXX`（AutoCAD 文本解析器认这个转义）。注意 escape 管不了**图层名**（图层名没有转义机制），
所以那种情况下把图层名一并改成英文最稳，脚本会在 `warnings` 里提醒。
预览 SVG 永远是 UTF-8 原文，一定看得见。

## 只要 dxf 不要预览
加 `--no-preview`。默认出预览是故意的：客户机上装了 CAD 的是少数。

## 什么时候**不该**用这个包
- 要效果图 / 渲染图 / 配图 → `uking-aigc`
- 要在客户**已有的** .dwg/.dxf 上改 → 本包做不到（只能新建）。如实说明，别悄悄重画一张交上去。
