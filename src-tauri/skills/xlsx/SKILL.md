# U-King 出真 Excel（uking-xlsx）

## 何时用
用户要做 Excel 表格、报表、数据整理、清单、台账、统计表等，需要能直接打开、数字能参与计算的 .xlsx 成品。

## 核心用法
**方式一：从 CSV（单表最快）**
1. 用 write_file 把数据写成 CSV（首行表头），比如 `data.csv`。
2. `node ~/.uking/skills/uking-xlsx/scripts/gen-xlsx.mjs --csv data.csv --out 表格.xlsx --json`

**方式二：多表 / 精确控制（book.json）**
```json
{ "sheets": [
  { "name": "销售", "rows": [ ["月份","销量","金额"], ["1月", 120, 3600], ["2月", 200, 6000] ] },
  { "name": "汇总", "rows": [ ["项目","值"], ["合计", 9600] ] } ] }
```
`node ~/.uking/skills/uking-xlsx/scripts/gen-xlsx.mjs --in book.json --out 报表.xlsx --json`

## 插图表（管理层要的报表基本都要一张图）
在某张 sheet 上加 `chart` 字段即可，出的是**原生可编辑 Excel 图表**（客户改数据图会跟着变），
不是贴图片：
```json
{ "sheets": [{
  "name": "月度营收",
  "rows": [["月份","营收_万元"],["1月",128],["2月",96],["3月",142]],
  "chart": {
    "type": "line",                                   // line 折线 / bar 柱状 / pie 饼
    "title": "上半年营收趋势",
    "categories": "A2:A4",                            // 分类轴（月份那一列，不含表头）
    "series": [{ "name": "营收_万元", "values": "B2:B4" }],
    "anchor": "E2"                                    // 可选，图放哪；不给就落在数据右边
  }
}]}
```
要点：
- **区间写成 `A2:A4` 这种 A1 地址**，不含表头行；脚本会自动补表名和 `$` 绝对地址。
- 一张 sheet 一张图。要多张图就多开几张 sheet。
- `series` 可以给多条（多条折线对比）。

🔴 **不要为了插图去 `npm install exceljs`**：客户机常常没网、npm 没配好、装到一半失败，
而这个包**零依赖、便携 Node 直接跑**。实测有人绕开本包去装 exceljs，在开发机上跑通了，
客户机上就是装不上。

## 要点
- **首行自动加粗当表头**。
- **数字自动识别为数值单元格**（如 `120`、`3.14`）——在 Excel 里能直接求和/做公式；要强制文本就在 JSON 里写成字符串且带非数字字符。
- 🔴 **两类「长得像数字」的值会按文本存，这是故意的**：**带前导零**的（工号 `007`、邮编 `010000`）和
  **有效位超过 15 位**的（18 位身份证、银行卡号、长订单号）。写成数值就等于让双精度浮点重新表达它，
  前导零会没、末几位会变 0，而且**静默无告警** —— 表格看着正常，直到有人拿去对账。
  宁可这一列不能求和，也不能算错。（金额/数量这类正常数字不受影响，照旧可求和）
- 一次可多张 sheet（`sheets` 数组）。
- 输出 `{"ok":true,"file":"…"}`，把路径给用户，可 Excel/WPS 打开。

## 配合
数据先让 AI 算好/整理好再落表；要图表可另出 HTML 图或在 Excel 里手动插图。

## 什么时候**不该**用这个包

用户给了一份**已有的**文件让你改其中的文字 —— 那要用 **uking-office-edit**：

```bash
node <uking-office-edit>/scripts/edit-office.mjs 文件 --replace "旧文本=>新文本" --json
```

用本包重新生成，会把他原来的模板/母版/样式全丢掉，而且客户是打开文件那一刻才发现的。
只有「结构性改动」（加删行列、改版式）才值得重新生成，且要先跟用户说清楚格式会重来。
